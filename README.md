The current files of Doppelganger, a David Lynch fangame that is dedicated to his artwork. We are hugely inspired by his work and began developing this game in tribute after his passing.

The current structure has the set up of a basic 3D character controller that works as the player, he can interact with the world around him, knocking over statues, talking to NPCs on the map and collecting items to use.

The game is currently unfinished but will be updated as it's worked on throughout the year.
